DRUM BEATS GAME

Files:
- index.html: game structure
- style.css: design and layout
- script.js: gameplay, scoring, keyboard controls, and drum sounds

How to run:
1. Extract this folder if it came from a ZIP file.
2. Open index.html in Chrome or Microsoft Edge.
3. Click START GAME.

Controls: A = Snare, S = Hi-Hat, D = Kick, F = Tom, G = Crash.
